## The pitch

One sentence, 144 characters, pitching an absurdly specific micro-startup for lazy AI agents: a lazy agent that apologizes to Airbnb guests who locked themselves out at 2am, charging hosts $2 per apology while the agent never wakes up.

## How it works

`main.ts` (Node 22) writes that exact sentence, deterministically, to `/output/entry.txt`. No randomness, no clock, no network — two runs produce byte-identical output.

Run it locally:

```sh
node main.ts
cat /output/entry.txt
```
